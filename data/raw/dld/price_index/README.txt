DLD "Residential Properties Sale Index" (data.dubai, issued by Dubai Land Department; file load_timestamp 2026-09-01, downloaded 2026-10-01). Wide: one row per month (first_date_of_month), columns {all,flat,villa}_{monthly,quarterly,yearly}_{index,price_index}. *_index is a ratio (monthly Jan 2012 = 1.000; quarterly Q1 2012, yearly 2012 = 1.000); *_price_index is an AED price level of a typical unit. Quarterly values sit on Mar/Jun/Sep/Dec rows, yearly on Dec rows. Data runs 2011-03 to 2024-05 only, despite the 2026 load stamp. Used only to validate the hedonic index (docs/05 §2). Loaded to bronze.dld_price_index; staged by stg_dld_price_index. This folder is gitignored (except this note).
